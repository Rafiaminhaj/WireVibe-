# 📋 Changelog

All notable changes to WireVibe are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-06-05

### 🎉 Initial Release — Open Source Hackathon 2026

#### ✨ Features
- **Interactive Canvas Engine** — Smooth freehand drawing with customizable brush sizes
- **Eraser Tool** — 8x fat eraser for quick rubbing with `destination-out` compositing
- **Color Picker** — Full color palette for wireframe sketching
- **Image Upload** — Upload existing wireframe images directly onto canvas
- **AI Code Generation** — Google Gemini 1.5 Flash Vision API integration
- **BYOK Security Model** — Bring Your Own Key stored in localStorage only
- **Demo Mode** — Works without API key using pre-built template
- **3D Card Flip Animation** — Cinematic CSS `preserve-3d` flip reveal
- **Scan Laser Overlay** — Animated scanning effect during AI processing
- **Live Preview** — Real-time iframe preview of generated code
- **Device Toggles** — Desktop (100%), Tablet (768px), Mobile (375px) viewports
- **Syntax Highlighting** — Highlight.js integration for generated code
- **One-Click Copy** — Clipboard API for instant code copying
- **HTML Export** — Download generated code as `.html` file
- **Confetti Celebration** — canvas-confetti animation on download
- **VibeBot Assistant** — Floating AI guide widget
- **Glassmorphism UI** — Modern frosted-glass design system
- **Responsive Design** — Works on desktop and mobile devices
- **Zero Dependencies** — Pure HTML, CSS, and Vanilla JavaScript
